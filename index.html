Nakatala rito ang mga salitang hindi pa naibibigay ang katumbas sa Datu Piang Maguindanaon.

Karne — Meat (hindi pa naibibigay ang Maguindanaon)
Prutas — Fruit (hindi pa naibibigay ang Maguindanaon)

☁️ Cloud Sync — ikonekta ang iyong dictionary

Para makita ang parehong mga salita sa iba’t ibang device, ikonekta ang app sa sarili mong Firebase project. Gamitin ang iisang account sa bawat device. Huwag ipadala sa chat ang password mo.

Hindi pa nakakonekta

Firebase web config (mula sa Firebase Console → Project settings → Your apps). Ilalagay ito sa app na ito; hindi ito password.

Hindi pa naka-set up ang cloud. Maaari pa ring gamitin ang app offline at mag-backup ng JSON file.

Backup at pagpapanumbalik

Awtomatikong sine-save ang mga pagbabago sa browser na ito. Mag-download ng backup paminsan-minsan para may kopya ka kung magpalit ng cellphone o browser.
